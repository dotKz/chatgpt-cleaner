# Security Policy

## Reporting a security issue

Please do **not** publish sensitive security details, access tokens, cookies or private ChatGPT data in a public issue.

For normal bugs that do not contain sensitive information, use GitHub Issues.

For a potentially sensitive report, contact the maintainer first:

- Maintainer: **dotKz**
- Discord: **kz.kz**

## Scope

ChatGPT Cleaner is a client-side userscript that runs on ChatGPT web pages. It does not operate a backend service and does not intentionally transmit data to third-party servers.

Because it uses undocumented internal ChatGPT web APIs, upstream behavior can change independently of this repository.
