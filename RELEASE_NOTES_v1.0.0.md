# ChatGPT Cleaner v1.0.0

First public release of **ChatGPT Cleaner**.

## Highlights

- Compact UI designed to blend into ChatGPT.
- Active, archived and selected conversation views.
- Project-aware filters and searchable project selector.
- Search and sorting for large conversation histories.
- Bulk archive, restore and delete actions.
- Automatic light/dark theme adaptation.
- Automatic ChatGPT/browser language detection with 15 interface languages.
- Progressive rendering, limited concurrency and retries for better performance on large histories.
- No third-party libraries, analytics or tracking.

## Installation

Install `chatgpt-cleaner.user.js` with Tampermonkey, then reload `chatgpt.com`.

## Important

This is an unofficial community project and is not affiliated with OpenAI. It relies on undocumented ChatGPT web APIs, so upstream changes can affect compatibility.
