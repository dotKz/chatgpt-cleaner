# Changelog

All notable changes to **ChatGPT Cleaner** will be documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-04

### Added

- Initial public release.
- Compact native-style conversation manager for ChatGPT.
- Active, archived and selected conversation views.
- Search across conversation titles and projects.
- Scope filters for all chats, project chats and chats outside projects.
- Searchable project selector.
- Sorting by newest, oldest, title and project.
- Bulk selection workflow with selected-items review.
- Bulk archive, restore and delete actions.
- Direct conversation opening from the manager.
- Automatic ChatGPT/browser language detection.
- 15 interface languages.
- Automatic dark/light theme adaptation.
- Progressive rendering and limited project-request concurrency.
- Retry handling for temporary request failures / rate limits.
- No third-party libraries, analytics or tracking.
